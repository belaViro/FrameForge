# 手绘科普信息图风格描述

## 整体风格

这组图片属于「手绘白板科普信息图」风格，整体像一张经过精心排版的课堂板书、知识卡片或短视频科普插画。画面以白色背景为主，内容通过手写标题、卡片分区、箭头流程、拟人化小图标、人物角色和简化场景组合成一页完整的知识讲解图。

风格的核心特点是：信息密度高，但视觉上保持轻松、亲切、可读。它不是写实插画，也不是扁平商务图标，而是带有明显手绘笔触、儿童绘本感和课堂讲义感的知识型插画。

## 画面比例与边界

图片主体通常是横向宽屏信息图，画面边缘直接延伸为白色背景，整体像一张完整的横向课件、白板讲义或知识卡片。

默认复刻时应遵循：

- 使用完整横向白色画布。
- 让信息图内容自然铺满画面，但保留足够留白。
- 画面边缘可以有少量装饰线条或小图标，但整体仍应保持干净。

## 构图特征

画面通常采用「大标题 + 多模块信息区」的结构。

顶部是非常醒目的手写大标题，占据画面上方主要位置。标题字形粗大、圆润、不规则，像马克笔或手写板书。标题常使用两到三种颜色混排，例如深蓝、绿色、橙色，用颜色强调关键词。

中部是主要讲解区，常见结构包括：

- 左右对比布局，例如 32 位 vs 64 位、软件版本 vs 硬件平台。
- 中心辐射布局，例如以 UDP 图标为中心，向四周发散多个应用场景。
- 流程图布局，例如从问题、传输、返回、结果依次推进。
- 四宫格或多卡片布局，每个格子解释一个概念。
- 时间线或路径式布局，用虚线箭头引导阅读顺序。

画面中大量使用圆角矩形、虚线框、编号圆点、箭头、对勾、叉号、标签条、气泡框等视觉组件。这些元素共同构成「手绘版课件」的感觉。

## 线条与笔触

线条是这种风格最重要的识别特征之一。整体线条看起来像手绘马克笔或数位板手写，而不是完全机械的矢量图。

线条特点包括：

- 黑色或深蓝色描边为主，线宽中等偏粗。
- 边缘略微不规则，有手写抖动感。
- 圆角很多，避免尖锐、冷硬的工业感。
- 箭头、虚线、框线都带有手绘感。
- 装饰线条常用短线、波浪线、放射线、虚线轨迹。

人物、设备、图标都使用简单清晰的外轮廓，细节不会过度复杂。阴影和体积感较弱，主要靠线条、浅色填充和局部高光表达。

## 色彩风格

整体色彩明亮、轻快、低压，适合知识科普和教学内容。背景大面积留白，彩色只用于标题、重点模块、图标和辅助标记。

常见主色包括：

- 深蓝色：用于标题、重要框线、技术概念。
- 绿色：用于正确、目标、完成、通过、积极含义。
- 橙色：用于对比、强调、警示、问题关键词。
- 浅紫色：用于标签、辅助说明、过渡信息。
- 黄色：用于灯泡、星星、重点提示、活泼装饰。
- 浅蓝色：用于屏幕、网络、科技背景、设备拟人。

颜色整体饱和度适中，不是强烈霓虹色，也不是沉闷商务色。常用浅色块作为底色，再用深色描边，形成柔和但清晰的信息层级。

## 字体与文字感

文字有明显手写感，尤其是标题和标签。标题像手写粗体马克笔字，字形不完全规整，有轻微大小变化和笔触差异。

正文文字相对更整齐，但仍保留手写风格。中文字符圆润、宽松，适合在科普场景中降低理解压力。英文、数字和技术词汇也以手写形式出现，例如 UDP、DNS、CPU、x64、ARM 等，看起来像课堂笔记中的技术标注。

文字排版通常遵循以下规律：

- 标题最大，位于顶部中央。
- 模块标题使用彩色胶囊标签或编号标签。
- 正文放在圆角框、卡片、气泡或插图旁边。
- 关键词用颜色、下划线、粗笔触或标签块强调。
- 说明文字不会完全居中堆叠，而是围绕图示自然分布。

## 图标与符号

图片中大量使用简化图标帮助理解技术概念。图标不是严肃的线性商务图标，而是可爱、圆润、手绘化的小插画。

常见图标包括：

- 电脑、手机、服务器、路由器、芯片、内存条。
- 书本、拼图、工具箱、齿轮、地图定位、目标靶。
- 对勾、叉号、感叹线、灯泡、星星、旗帜。
- Wi-Fi、数据包、信号波、网络节点、箭头路径。

很多图标带有拟人化表情，例如电脑屏幕、UDP 数据包、房子、设备会出现眼睛和微笑。这种处理让抽象技术概念变得轻松、具象、容易被普通观众接受。

## 人物角色

人物形象是可爱手绘卡通风，比例偏 Q 版，但不是极端夸张的二头身。人物通常有圆脸、黑色头发、红润脸颊、简单表情和休闲服装。

人物常承担以下作用：

- 作为讲解者，出现在画面边角或模块旁边。
- 作为学习者，表达困惑、理解、点赞等状态。
- 作为比喻角色，例如快递员、用户、开发者。
- 用手势引导观众注意重点内容。

人物表情友好、积极，情绪表达简单直接。服装常见颜色为蓝色、绿色、黄色等，与整体配色保持一致。

## 信息组织方式

这类图片的重点是「把技术概念讲简单」。画面不追求单一视觉冲击，而是追求知识结构清晰。

常见的信息组织方法包括：

- 用左右对比解释区别。
- 用箭头表示过程。
- 用编号拆解步骤。
- 用卡片承载独立知识点。
- 用拟人化比喻解释抽象概念。
- 用对勾和叉号表达兼容与不兼容。
- 用道路、桥梁、快递、广播等生活场景类比网络或计算机概念。

整体阅读路径通常非常明确：先看顶部标题，再跟随箭头、编号或分区逐步理解。

## 装饰元素

画面周围常有少量手绘装饰，但不会喧宾夺主。这些装饰让画面更活泼，也填补留白区域。

常见装饰包括：

- 小星星。
- 放射短线。
- 虚线飞行轨迹。
- 小旗子。
- 手绘下划线。
- 小爱心。
- 波浪线。
- 圆点路径。
- 简单的纸飞机或定位标记。

装饰通常分布在标题附近、边角、箭头路径旁或模块之间，用来增强节奏感。

## 场景与隐喻

虽然主题多为计算机、网络、软件版本等技术概念，但画面会大量使用生活化隐喻。

例如：

- 用道路宽窄比喻 32 位与 64 位的数据处理能力。
- 用桥梁比喻架构与版本之间的沟通。
- 用快递员比喻 UDP 的不可靠传输。
- 用广播和多播场景解释网络通信。
- 用本机、局域网、设备群解释特殊地址。

这些隐喻场景通常是浅色、简洁、可爱的手绘小场景，不强调真实透视，而强调概念关系。

## 质感与光影

画面整体光影非常轻。多数元素是平面手绘填色，只有少量浅阴影、浅蓝高光或灰色投影。

质感特点包括：

- 背景近乎纯白，像白纸或白板。
- 色块边缘柔和，不追求真实材质。
- 设备屏幕常用浅蓝渐变或淡色填充。
- 阴影通常很浅，只用于让人物或物体稍微落地。
- 不使用复杂光源、强烈明暗对比或写实纹理。

这种处理让画面保持清爽，适合承载大量文字和信息。

## 可复刻的提示词方向

可以用以下方向描述这种图片：

手绘白板科普信息图，完整白色背景，横向宽屏课件感，大号手写中文标题，蓝色绿色橙色关键词，高信息密度排版，圆角卡片分区，虚线箭头流程，编号标签，对勾和叉号，手绘电脑、手机、服务器、芯片、网络图标，可爱拟人化设备，Q 版人物角色，轻松课堂讲义风，马克笔线条，粗黑描边，浅色填充，少量星星和放射线装饰，清晰易懂的技术科普插画。

## 负面约束

复刻时应避免以下方向：

- 不要做成写实 3D 渲染。
- 不要使用深色背景作为主体。
- 不要做成极简商务 PPT 图标风。
- 不要使用复杂摄影质感。
- 不要使用强烈霓虹光效。
- 不要让画面只有单个主体，缺少信息图结构。
- 不要让字体过于机械规整，应保留手写感。
