# 5 分钟科普视频方案：什么是 AI 智能体？

## 基本定位

- **标题**：什么是 AI 智能体？从“会聊天”到“会干活”
- **时长**：约 5 分钟
- **受众**：对 AI 感兴趣，但不一定懂技术的普通观众
- **风格**：手绘白板科普信息图 + 男声配音 + 关键词字幕
- **核心类比**：Chatbot 像客服，Agent 像员工
- **核心观点**：AI Agent 不是更会聊天的 AI，而是能围绕目标，规划步骤，调用工具，并根据结果继续行动的 AI 系统。

## 口播脚本

### 0:00-0:20 钩子

你以为 AI 智能体，就是一个更聪明的 ChatGPT？

其实不是。

ChatGPT 更像一个坐在窗口里的客服，你问一句，它答一句。

而 AI 智能体，更像一个真正的员工。你给它一个目标，它会自己拆任务、查资料、用工具、执行动作，甚至做完以后还会回头检查。

这就是 AI 从“会聊天”，走向“会干活”的关键一步。

### 0:20-1:05 Chatbot 和 Agent 的区别

先看一个最简单的区别。

如果你对聊天机器人说：帮我整理一份竞品分析。

普通 Chatbot 通常会直接开始写一段内容。它的主要能力，是根据已有知识生成回答。

但 Agent 会多做几步。

它可能先问：竞品是谁？分析维度是什么？要不要查最新资料？

然后它会打开搜索工具，收集网页信息，整理成表格，再生成报告。

如果发现数据不够，它还会继续补查。

所以，Chatbot 的工作方式是“回答问题”。

Agent 的工作方式是“完成目标”。

这个差别非常大。因为一旦 AI 能围绕目标持续行动，它就不再只是一个聊天窗口，而开始接近一个数字员工。

### 1:05-2:00 Agent 的四个核心部件

一个 AI Agent 通常有四个核心部件。

第一个，是大模型。

它相当于大脑，负责理解任务、生成计划、判断下一步该做什么。

第二个，是工具。

比如搜索、计算器、浏览器、代码执行器、数据库、邮件、日历、表格软件。没有工具的 AI，只能“想”；有了工具，它才能“做”。

第三个，是记忆。

短期记忆记录当前任务做到哪一步，长期记忆保存用户偏好、历史经验和常用资料。

第四个，是循环。

Agent 不是一次性回答完就结束，而是不断重复：思考、行动、观察结果，再继续思考。

这也是很多 Agent 框架最核心的模式：先想一步，做一步，看结果，再决定下一步。

你可以把它想象成一个实习生。大模型是脑子，工具是手，记忆是笔记本，循环就是它不断试错和推进任务的过程。

### 2:00-3:05 一个真实任务怎么跑

我们用一个具体例子。

你对 Agent 说：帮我做一个关于“AI 客服”的市场调研，输出一页总结。

第一步，它会理解目标：我要做的是市场调研，不是写广告文案。

第二步，它会拆任务：先查行业现状，再找典型公司，再总结优势和风险，最后整理成一页报告。

第三步，它会调用工具。比如打开搜索，查资料；打开网页，读内容；打开表格，整理信息；必要时还会调用写作工具生成摘要。

第四步，它会检查结果。比如发现某个数据没有来源，就重新搜索；发现报告太长，就压缩成一页。

最后，它才把结果交给你。

这整个过程，和普通 ChatGPT 最大的不同是：它不是在一次回答里假装完成任务，而是真的把任务拆成多个步骤，并且每一步都可能调用外部工具。

所以，Agent 的能力上限，不只取决于模型有多聪明，还取决于它能连接多少工具，以及能不能稳定地把流程跑完。

### 3:05-4:05 Agent 为什么突然火了

那为什么这两年 Agent 突然火了？

因为三个条件终于凑齐了。

第一，大模型变强了。

它不只是能续写文字，还能理解复杂指令，做简单规划，读懂工具返回的结果。

第二，工具调用成熟了。

过去 AI 说“我可以帮你查”，很多时候只是嘴上说说。现在它真的可以调用搜索、执行代码、操作文件、访问数据库。

第三，大家开始需要自动化。

写周报、做表格、整理资料、写代码、查订单、回复客户，这些任务都有一个共同特点：步骤多、重复高、需要一点判断，但不一定每一步都需要人亲自做。

Agent 正好卡在这个位置。

它不是魔法，也不是通用人工智能，而是把大模型、工具和流程编排到一起，让 AI 能承担一部分复杂工作。

### 4:05-4:45 Agent 的边界和风险

但是，Agent 也没有很多宣传里说得那么神。

它会犯错。

比如任务拆错、工具用错、网页看错、结果编错，甚至在一个步骤里卡住，反复绕圈。

它也有成本。

一个普通聊天可能只消耗一次模型调用，但 Agent 做一个任务，可能要调用十几次模型、查很多网页、跑多轮工具，费用和时间都会变高。

它还需要安全边界。

如果一个 Agent 能操作文件、发邮件、下订单、改数据库，那就必须限制权限。否则，一个错误指令就可能造成真实损失。

所以，今天最靠谱的用法，不是让 Agent 完全替代人，而是让它做人类的执行助手。

人负责目标、判断和最终决策。

Agent 负责拆解、执行和整理。

### 4:45-5:00 总结与互动

一句话总结：

Chatbot 是会回答问题的 AI，Agent 是会推进任务的 AI。

它的本质，不是“更会聊天”，而是“能用工具完成目标”。

你最希望 AI Agent 帮你自动完成哪件事？整理资料、写代码、做表格，还是处理工作消息？

评论区告诉我。下一期，我们讲 Agent 最关键的能力：工具调用到底是怎么工作的。

## 制作建议

- **配音速度**：控制在每分钟 260-300 个中文字左右。
- **字幕**：保留逐字高亮，但不要让字幕遮挡核心图示。
- **图片数量**：建议 8-10 张主图，每张图承载一个知识点。
- **节奏**：每 25-35 秒切换一张主图，中间用局部放大、箭头高亮、卡片弹出增强动态。
- **结尾互动**：用“你最想让 Agent 自动完成哪件事？”引导评论。
