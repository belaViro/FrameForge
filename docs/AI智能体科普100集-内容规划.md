# AI 智能体科普系列 — 100 集内容规划

## 账号定位

- **平台**: 抖音（主）、视频号/B站（副）
- **定位**: AI 智能体原理 + AI 应用科普
- **风格**: 动画可视化 + 男声配音，60 秒左右/集
- **更新频率**: 每周 3-5 更，预计 5-7 个月完成
- **目标受众**: 对 AI 感兴趣的泛科技人群（非程序员也能看懂）

---

## 视频规格

| 参数 | 值 |
|------|-----|
| 分辨率 | 1080x1920（竖屏 9:16） |
| 时长 | 60 秒左右（约 1800 帧 @30fps，按配音长度微调） |
| 格式 | MP4 H.264 |
| 配音 | Edge TTS zh-CN-YunyangNeural（男声） |
| 字幕 | 逐字高亮（TikTok 风格） |
| 片头 | 0.5 秒品牌动画 |
| 片尾 | 关注引导 + 下集预告 |

---

## 每集结构模板

```
[0-3s]   钩子（冲突/悬念/反直觉，必须 3 秒内抓住人）
[3-48s]  核心内容（一个概念 + 一个类比 + 动画演示）
[48-55s] 一句话金句总结
[55-60s] 引导关注 + 预告下集
```

## 技术生产线

### 项目标准

以 `D:\财富密码\视频号\Remotion-created` 现有项目为制作标准：

- 每集一个 Remotion 组件：`src/Episode01.tsx`、`src/Episode02.tsx`、`src/Episode03.tsx` ...
- 入口统一注册在：`src/Root.tsx`
- 配音文件放在：`public/audio/ep01.mp3`、`public/audio/ep02.mp3` ...
- 成片输出到：`out/Episode01.mp4`、`out/Episode02.mp4` ...
- 封面输出到：`out/cover_ep01.png`、`out/cover_ep02.png` ...
- 视频规格沿用现有项目：1080x1920、30fps、H.264 MP4

### 批量生产流程

```
选题/脚本数据
    ↓
scripts/generate-tts.mjs（Edge TTS 男声配音）
    ↓
public/audio/epXX.mp3
    ↓
src/EpisodeXX.tsx（按现有 1-3 集风格制作动画）
    ↓
npm run build -- EpisodeXX out/EpisodeXX.mp4
    ↓
out/EpisodeXX.mp4 + out/cover_epXX.png
```

### 数据格式

```json
{
  "id": 1,
  "title": "AI 不是在思考，是在预测下一个字",
  "hook": "ChatGPT 其实是一个超级填空机器",
  "script": "你以为 AI 在思考？其实它只是在做一件事...",
  "summary": "AI 的本质是概率预测，不是真正的理解",
  "nextPreview": "下集：Token 是什么",
  "animationType": "typewriter",
  "accentColor": "#4fb3ff"
}
```
